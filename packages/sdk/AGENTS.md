# packages/sdk — typed API client

- `src/schema.ts` is generated by `openapi-typescript` from `apps/api/openapi.json`. Never edit it by hand: run `pnpm contract` at the root. CI fails when it's stale. See ADR 0004.
- `src/index.ts` stays a thin wrapper: `createApiClient(baseUrl)` over `openapi-fetch`, plus type re-exports. No per-endpoint functions, caching, or React hooks; those belong in `apps/web`.
- Only server code in `apps/web` calls the API (the web app is the BFF).
